# 🍕 Pizza Sales Analysis – Power BI Dashboard

##  Project Overview
This project analyzes pizza sales data using Power BI to uncover insights related to revenue, order trends, pizza sizes, and product performance.  
The goal is to help business stakeholders understand sales patterns and make data-driven decisions.

---

##  Tools Used
- Power BI
- DAX (Data Analysis Expressions)
- CSV datasets

---

##  Dataset
The project uses multiple CSV files representing different parts of the business data:
- Orders
- Order details
- Pizzas
- Pizza types

These files were loaded directly into Power BI and modeled using relationships.

---

##  Key KPIs
- Total Orders
- Total Revenue
- Average Order Value (AOV)
- Average Pizzas per Order

---

##  Dashboard Features
- Revenue analysis by pizza size and category
- Peak order analysis by hour, day, and month
- Top 10 and Bottom 10 pizzas based on revenue
- Interactive slicers for category, size, and date

---

##  Key Insights
- Large-sized pizzas generate the highest share of revenue
- Classic category contributes the most to overall sales
- Orders peak during lunch and evening hours
- Weekend demand is higher than weekdays
- Bottom-performing pizzas indicates improving status

---

## ▶️ How to Use
1. Download the repository
2. Open the `.pbix` file in Power BI Desktop
3. Refresh the data if required
4. Explore insights using slicers and visuals
